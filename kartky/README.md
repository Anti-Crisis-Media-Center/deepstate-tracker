# Листівки до визначних дат

Бот бере дати з Google-календаря «Визначні події АКМЦ», картки — з Диску АКМЦ
(папка «Визначні дати АКМЦ (листівки для соцмереж)») і публікує о 8:30.
Напередодні о 18:00 — превʼю в Суперчаті АКМЦ, гілка «Тести».

## Що робить редакторка

1. **Картки** — у підпапку «ММ.ДД Назва», напр. «11.20 День захисту дітей».
   Розміри: 1080×1080 (Telegram, Facebook), 1080×1350 (Instagram, Threads), 1080×1920 (сторіз).
   Файл зі словом «вручну» в назві бот пропускає.
2. **Тексти** — в описі події, під мітками (кожна мітка окремим рядком):

```
#TG
Текст для Telegram (жирний і посилання тут працюють)

#FB_БІЛА
Текст для білої сторінки Facebook «У фокусі» (без хештегів і посилань)

#FB_ЖОВТА
Текст для жовтої сторінки «Антикризовий медіа-центр» (інший, ніж для білої)

#IG
Текст для Instagram з хештегами

#THREADS
Текст для Threads (до 500 знаків)

Тема: День захисту дітей

#СТОРІЗ

#ALT
Короткий опис картинки для незрячих (необов'язково)
```

* Немає мітки — у цю мережу нічого не йде.
* Текст над першою міткою — нотатки, не публікується.
* `#СТОП` окремим рядком — дату пропустити.

## Що робить бот

* 18:00 напередодні — превʼю кожної мережі + перелік ✅/❌/⚠️ і кнопка «❌ Не публікувати».
* 8:30 — публікація: Telegram @acmc_ua (без звуку), Facebook — жовта й біла сторінки,
  Instagram, Threads, сторіз (Facebook + Instagram). Потім звіт із посиланнями.
* Після публікації папка дати переїжджає в «Опубліковано РРРР».

Тестовий режим: `KARTKY_TEST: "1"` у `.github/workflows/kartky.yml` — у соцмережі нічого не йде.
Ручний запуск: Actions → «Листівки до визначних дат» → Run workflow.
