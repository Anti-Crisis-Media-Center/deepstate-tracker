## Де що знайти

- **Код і розклад:** github.com/Anti-Crisis-Media-Center → репозиторій → вкладка **Actions** (тут видно кожен запуск: зелений — добре, червоний — збій).
- **Ключі ботів:** репозиторій → **Settings** → **Secrets and variables** → **Actions**. Прочитати ключ не можна, лише замінити.
  - deepstate-tracker: `TELEGRAM_BOT_TOKEN` (Новинар), `ANALYTICS_BOT_TOKEN` (Аналітика).
  - memorial-bot: `MEMORIAL_BOT_TOKEN` (Меморіал), `TELEGRAM_BOT_TOKEN` (Новинар — запасний).
- **Хто власник бота:** усі три боти належать службовому Telegram-акаунту **«АКМЦ Робочий» (@acmcua)** (не особистому акаунту Юлі). Доступ до «АКМЦ Робочого» мають Юля й Тетяна. Фізична SIM-картка номера цього акаунта — у Тетяни Андрєєвої (коди входу з нових пристроїв приходять на неї). Двоетапна перевірка (хмарний пароль) увімкнена 10.11.2026; пароль — у Менеджері паролів Google акаунта acmc.ua@gmail.com (запис telegram.org, «АКМЦ Робочий @acmcua»), пошта для відновлення — acmc.ua@gmail.com. Список ботів: увійти в Telegram як «АКМЦ Робочий» → @BotFather → `/mybots`.
- **Чи бот адміністратор каналу:** @acmc_ua → назва каналу → **Змінити** → **Адміністратори**. Новинар-бот має бути там із правом **«Публікувати повідомлення»**.
- **Помилки:** службова група, гілка «Помилки». Якщо щось зламалося, бот пише туди сам.

## Що робити, якщо…

### Щось публікується неправильно — терміново зупинити
Найшвидше (хвилина, з телефона):
1. @acmc_ua → **Змінити** → **Адміністратори** → потрібний бот → **Звільнити з адміністраторів** (Dismiss admin). Бот одразу перестає публікувати в канал.

Акуратніше (зупиняє програму, бот лишається адміном):
2. GitHub → репозиторій → **Actions** → ліворуч потрібна задача («DeepState — моніторинг змін», «Хвилина мовчання», «Аналітика соцмереж…») → **⋯** → **Disable workflow**.

Увімкнути назад: повернути бота адміністратором із правом публікувати / **Enable workflow**.

### Меморіал: сьогоднішній пост не має виходити
- Якщо чернетка прийшла тобі: кнопка **⛔ Не публікувати**.
- Якщо чернетки бачить лише Юля: GitHub → memorial-bot → **Actions** → «Хвилина мовчання» → **Run workflow** → mode **`skip`** → **Run workflow**.

### Ключ бота міг потрапити до сторонніх (скриншот, пересланий лист, зламаний акаунт)
Робить той, хто має доступ до акаунта «АКМЦ Робочий» (Юля або Тетяна):
1. Увійти як «АКМЦ Робочий» → @BotFather → `/mybots` → бот → **API Token** → **Revoke current token**. Старий ключ перестає працювати миттєво, BotFather видає новий.
2. Вставити новий ключ у GitHub: секрет бота (див. «Де що знайти») → олівець → **Update secret**.
3. **Лише для Новинар-бота:** ще й у Make → **Credentials** → **Connections** → «АКМЦ Новинар-бот» → **Edit** → новий токен. Інакше стрічка новин зупиниться.
4. Ключ нікому не пересилати.

### Юля недоступна надовго
Першого тижня (робить Тетяна або інша відповідальна людина):
1. **Чернетки Меморіалу перевести на себе:** відкрити «АКМЦ Меморіал-бот» → **Start** → дізнатися свій номер Telegram у @userinfobot → GitHub → memorial-bot → секрет `REVIEW_CHAT_ID` → замінити на свій номер. Без цього бот однаково публікує о 9:00, просто ніхто не бачить чернетку.
2. **Стати адміністраторкою службової групи** і читати гілку «Помилки».
3. **TikTok і YouTube:** щопонеділка о 8:20 відео й підпис приходять у гілку «TikTok» — хтось має їх викласти вручну. Якщо нікому — нічого не зламається.

Протягом місяця:
4. **Власність ботів міняти не треба:** вони належать службовому акаунту «АКМЦ Робочий», і Тетяна має до нього доступ. Достатньо переконатися, що вхід в «АКМЦ Робочий» працює (пароль і двоетапна перевірка — у Google Password Manager) і що коди входу приходять не лише на телефон Юлі.
5. Оновити «01 Доступи» і цей документ.

### Бот мовчить, а мав написати
1. GitHub → репозиторій → **Actions** → чи є сьогоднішній запуск і чи він зелений.
2. Червоний — відкрити → подивитися журнал; часто це тимчасовий збій сайту DeepState чи «Меморіалу», наступний запуск проходить сам. Повторити вручну: **Run workflow**.
3. Запуску немає зовсім — GitHub іноді запізнюється на 10–30 хвилин; DeepState-бот сам чекає до потрібного часу й має запасний запуск.
4. Бот більше не адміністратор каналу — повернути (див. вище).

## Що НЕ робити
- Не видаляти ботів у @BotFather і не видаляти їх із каналу «щоб перевірити» — краще **Disable workflow**.
- Не змінювати назви секретів у GitHub — лише значення.
- Не пересилати ключі ботів у чати, листи, Claude.
- Не вмикати бота в інших каналах чи групах без потреби.
