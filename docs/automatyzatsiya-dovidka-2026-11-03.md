## 1. DeepState-трекер

**Що робить:** щодня порівнює мапу DeepState з попередньою версією для Донецької та Луганської областей і публікує пост у Telegram-канал АКМЦ @acmc_ua. Без ШІ: розрахунки + текст за шаблоном.

**Розклад:** доба — щодня 8:00 (Київ); тиждень — пн 8:10; місяць — 1-го 8:20. GitHub запускає задачу завчасно (cron 04:30 і 05:30 UTC, запасний 08:17 UTC), скрипт сам чекає до 8:00.

**Файли:** `tracker.py` (`PUBLISH_HOUR = 8`, `SUMMARY_DELAY_MINUTES = {"week": 10, "month": 20}`), обкладинки `cover.jpg`, `cover_week.jpg`, `cover_month.jpg`, папка `data/`.

**Щоденний пост:** км² змін на окуповані / деокуповані по кожній області + найближчі населені пункти з районом (радіус 5 км); «Повідомлення на сайті DeepState» (`https://deepstatemap.live/api/history/public`) лише про Донеччину/Луганщину; загальну площу й % у щоденному НЕ показуємо; скрізь «мапа», не «карта».

**Тижневий / місячний підсумок:** суми км², у скількох днях були зміни, населені пункти за частотою (до 6), баланс за період, загальна площа й %. Тижневий — зі списком повідомлень DeepState (до 12). Потрібно ≥6 днів даних для тижня, ≥25 — для місяця.

**Джерела даних:** `https://deepstatemap.live/api/history/last`; межі областей OCHA (cod_ab_ukr_v05, UA14/UA44); населені пункти ADM4 (2 224) — `data/reference/`.
