# 07 Стрічка новин сайту → Telegram — Make

*Станом на 11.11.2026. Для тих, хто підтримує автоматизацію без Юлі.*

## Коротко

Нові матеріали з сайту acmc.ua самі з'являються в Telegram-каналі **@acmc_ua**. Це робить сценарій Make **«📰 АКМЦ | Новини сайту → Телеграм (Робочий)»**:

- кожні 15 хвилин він перевіряє RSS сайту (`https://acmc.ua/feed/`);
- бере нові матеріали — до 2 за один запуск, решту забирає наступного разу;
- готує текст поста через ChatGPT і публікує його з картинкою від імені **@acmc_news_bot** (Новинар-бот).

Людина нічого не натискає. Втручатися треба лише тоді, коли пости перестали з'являтися або вийшли з помилками.

## Що відбувається з кожним матеріалом

1. **RSS** — сценарій бачить новий матеріал: заголовок, посилання, рубрики.
2. **Завантаження сторінки** — бере HTML повного матеріалу з сайту.
3. **Парсери** — витягують із HTML:
   - тіло статті (блок `<article class="article col-xs-12">`);
   - цитати (`<blockquote>`);
   - лід (перший абзац, виділений жирним);
   - перший абзац;
   - головну картинку (`og:image`).
4. **Маркування за рубрикою на сайті:** реклама → `#реклама`, ексклюзив → `#ексклюзив`, подкаст → `#подкаст`, партнерський матеріал → `#партнерськийматеріал`, відео → `#відео`. Якщо рубрики немає, маркування немає.
5. **Основний абзац:** для звичайної новини й ексклюзиву — лід; для реклами, партнерського, подкасту й відео — перший абзац.
6. **ChatGPT (модель GPT-5.4)** оформлює пост за редакційними правилами:
   - абзац не переписує;
   - посилання на сайт ставить на головне дієслово;
   - для ексклюзиву додає заголовок, за потреби цитату і фразу «Більше – читайте у матеріалі»;
   - для реклами, партнерського, подкасту й відео додає заголовок жирним.
7. **Перевірка довжини:** підпис до фото в Telegram — не більше 1024 символів. Якщо текст довший за 990, сценарій прибирає цитату.
8. **Публікація** в @acmc_ua: фото + текст + маркування, а для звичайних новин замість маркування — посилання «Підписатися». Сповіщення підписникам вимкнені (тихі пости).

Повний текст правил для ChatGPT — у самому сценарії, модуль OpenAI, поле Prompt. Правила змінювати лише за погодженням із головною редакторкою.

## Де це в Make

- **Make → Scenarios** → «📰 АКМЦ | Новини сайту → Телеграм (Робочий)». Перемикач праворуч має бути **ON**, розклад — кожні 15 хвилин.
- **Підключення (Connections)**, без яких сценарій не працює:
  - **Telegram Bot** — ключ @acmc_news_bot;
  - **OpenAI** — ключ API ChatGPT (оплачується окремо).

  Самі ключі зберігаються лише в Make і в Google Password Manager. Не пересилай їх у чати й документи.
- **Резервна копія сценарію** — файл `.blueprint.json` у цій папці на Диску. За ним сценарій можна відновити: **Scenarios** → **Create a new scenario** → ⋯ → **Import Blueprint**. Після імпорту треба знову вибрати підключення Telegram і OpenAI.

## Якщо пости перестали з'являтися

Відкрий сценарій → вкладка **History**: червоні рядки — помилки. Натисни на рядок, і Make покаже, на якому модулі зупинилося.

| Що бачиш | Причина | Що робити |
|---|---|---|
| Сценарій вимкнений (OFF) | Make сам вимикає сценарій після 3 помилок поспіль | Виправити причину (рядки нижче), потім увімкнути перемикач |
| Помилка в модулі OpenAI (401, 429, insufficient_quota) | Закінчилися гроші на рахунку OpenAI або ключ недійсний | Поповнити рахунок OpenAI або вставити новий ключ у Connections → OpenAI |
| Помилка в модулі Telegram (401 Unauthorized) | Ключ @acmc_news_bot змінили в @BotFather | Connections → Telegram → вставити новий ключ. **Важливо:** коли міняєте ключ Новинар-бота, міняйте його і в Make, і в секретах GitHub (DeepState) |
| Помилка Telegram «caption is too long» | Текст довший за 1024 символи навіть без цитати | Опублікувати цей матеріал вручну; повторюється часто — сказати Юлі |
| Помилка Telegram «wrong file identifier / failed to get HTTP URL content» | Сайт віддав картинку, яку Telegram не може завантажити | Опублікувати вручну; перевірити картинку матеріалу на сайті |
| Пост вийшов без ліду, порожній або дивний | Змінилася верстка сайту, і парсери не знаходять текст | Сказати Юлі. Після редизайну чи ребрендингу сайту сценарій **обов'язково перевірити** |
| Матеріал без головної картинки не вийшов зовсім | Сценарій зараз публікує лише матеріали з картинкою (див. нижче) | Опублікувати вручну або додати картинку на сайті |
| Помилок немає, але й нових постів немає | На сайті нічого нового або RSS не оновлюється | Відкрити `https://acmc.ua/feed/` у браузері й перевірити, чи є там нові матеріали |

**Ручний запуск:** у сценарії кнопка **Run once** — сценарій одразу перевірить RSS.

## Відомі обмеження (станом на 11.11.2026)

1. **Матеріали без картинки не публікуються.** У сценарії є гілка лише для «Є картинка», а гілки для матеріалу без картинки немає. Такий матеріал тихо пропускається, без помилки.
2. **Довгі пости.** Якщо текст довший за 1024 символи навіть без цитати, Telegram поверне помилку. Три такі помилки поспіль вимкнуть сценарій.
3. **Залежність від верстки сайту.** Парсери шукають конкретні HTML-класи. Зміна шаблону сайту може зламати витягування ліду й цитат.
4. **ChatGPT може помилитися** з вибором дієслова для посилання чи з цитатою. Редакторці варто переглядати стрічку.

## Доступи

- **Make:** хто має доступ і з якою роллю — див. «01 Доступи і відновлення». У Make має бути щонайменше дві людини з правами на редагування сценаріїв: Юля і Тетяна.
- **OpenAI:** акаунт і оплата — див. «01 Доступи і відновлення».
- **Новинар-бот (@acmc_news_bot):** власник — службовий акаунт «АКМЦ Робочий», див. «03 Боти АКМЦ».
