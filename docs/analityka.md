# 06 Аналітика — щотижневий звіт і YouTube

Оновлено: 11 листопада 2026 · Юля

## Що це

Щопонеділка о 10:00 «АКМЦ Аналітика-бот» (@acmc_analytics_bot) надсилає звіт у службову групу «Тестування ботів АКМЦ», гілку **«Аналітика»**. Людина нічого не робить — звіт збирається сам (GitHub, репозиторій deepstate-tracker, задача «Аналітика соцмереж — щотижневий звіт»).

## Що в звіті

| Платформа | Що показує |
|---|---|
| **Telegram @acmc_ua** | Підписники і зміна за період, перегляди, топ-3 дописи |
| **Facebook «У фокусі» (біла)** | Охоплення, підписники, топ-3 дописи з реакціями й коментарями |
| **Instagram** | Охоплення, підписники, топ-3 дописи / Reels |
| **Threads** | Перегляди, підписники, топ-3 дописи |
| **TikTok** | Перегляди, підписники, останні відео |
| **YouTube: «Антикризовий медіа-центр» і «Перевірено на Сході»** | Підписники, нові відео за період: перегляди, вподобання, коментарі |

Окремо по кожній платформі — дописи DeepState, щоб видно було, як працює рубрика.
У дужках — зміна до попереднього періоду такої самої довжини.

**Чого у звіті немає** (дивитися вручну в самих платформах):
- звідки прийшли нові підписники Telegram — канал → ⋮ → **Статистика** → «Нові підписники за джерелом»; скільки прийшло за нашими посиланнями з Threads і Facebook — з акаунта «АКМЦ Робочий»: **Змінити** → **Тип каналу** → **Керувати запрошувальними посиланнями**;
- час перегляду, утримання й джерела переглядів YouTube — YouTube Studio → **Аналітика**.

## Як отримати звіт позачергово, за будь-який період

**Кнопками в Telegram (з 10.11.2026).** Службова група → гілка «Аналітика» → закріплене повідомлення бота «📊 Звіт аналітики на вимогу» → натиснути **Доба / 3 дні / 7 днів / 14 днів / 30 днів**. Бот відповість «⏳ Готую звіт…», сам звіт прийде за 2–5 хвилин.

**Будь-який інший період** — написати в гілці «Аналітика» `/report`, пробіл і кількість днів, за які потрібен звіт (від 1 до 90):

| Що потрібно | Що написати |
|---|---|
| Звіт за 5 днів | `/report 5` |
| За два тижні | `/report 14` (або кнопка **14 днів**) |
| За квартал | `/report 90` |

Важливо:
- Пишіть саме з `/report` і пробілом. Просто число («5») чи слово («доба») бот не бачить.
- **Період ковзний:** рахується від моменту запиту назад. «Доба» о 20:24 — це з учора 20:24 до сьогодні 20:24, «7 днів» у вівторок — з минулого вівторка. Точний період — у заголовку звіту (для доби й 3 днів — з часом).
- Звіт за конкретні календарні дати (наприклад, лише жовтень) кнопками не замовити. Для цього — запасний шлях нижче або попросіть Claude.

**Запасний шлях, якщо кнопки не працюють:** GitHub → репозиторій **deepstate-tracker** → **Actions** → ліворуч «Аналітика соцмереж — щотижневий звіт» → **Run workflow** → у полі днів вказати число → **Run workflow**.

Як влаштовані кнопки і як їх налаштувати з нуля — документ «06б Кнопки аналітики — Make».

## YouTube

Ключ YouTube лежить у GitHub (секрет `YOUTUBE_API_KEY`), створений у Google Cloud акаунта acmc.ua@gmail.com, проєкт «ACMC Analytics». Канали — у змінній `YOUTUBE_CHANNELS` (ID через кому). Один ключ читає публічні дані будь-якого каналу, тож доступ до самих каналів не потрібен. Як замінити ключ чи додати канал — документ «YouTube-аналітика — налаштування» (технічні подробиці).

## Що робити, якщо…

- **Звіт не прийшов у понеділок** — GitHub → **Actions** → чи є запуск о 10:00 і чи він зелений. Червоний — відкрити журнал; часто тимчасовий збій однієї платформи, решта звіту приходить. Повторити: **Run workflow**.
- **У звіті «помилка» по одній платформі** — найчастіше спливає токен. Instagram/Facebook/Threads — див. «01 Доступи», TikTok — там само; YouTube — «YouTube-аналітика — налаштування».
- **YouTube — що є і чого немає.** Є: підписники, нові відео за період і їхні перегляди, рядок «🗺 DeepState» з плейлиста «DeepState: зміни на мапі…» (поки відео немає — «плейлист є, відео в ньому ще немає»). Немає: охоплення (покази), утримання, середній час перегляду — їх YouTube віддає лише власнику каналу; потрібне окреме підключення YouTube Analytics (заплановано).
- **Немає YouTube-блоку** — перевірити, що секрет `YOUTUBE_API_KEY` і змінна `YOUTUBE_CHANNELS` на місці.
- **Кнопки не відповідають** (немає навіть «⏳ Готую звіт…») — див. «06б Кнопки аналітики — Make», розділ «Що робити, якщо кнопки замовкли». Тим часом — запасний шлях через GitHub (вище).
