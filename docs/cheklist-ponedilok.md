# 05 Чекліст: понеділок і 1-ше число — що зробити вручну

Оновлено: 11 листопада 2026 · Юля (TikTok і YouTube оновимо після 16.11)

Для того, хто підміняє Юлю. Усе інше бот робить сам. На все разом —
15–20 хвилин.

Де все лежить: Telegram → службова група **«Тестування ботів АКМЦ»** →
гілка **«TikTok»**. Туди бот надсилає відео, готові тексти й картинку
для сторіз.

## Коли

| День                        | Коли  | Що прийде в гілку «TikTok»                                                          |
|-----------------------------|-------|-------------------------------------------------------------------------------------|
| Понеділок                   | ≈8:15 | Відео тижня, підпис для TikTok, текст «▶️ YouTube Shorts», картинка «📱 Для сторіз» |
| 1-ше число місяця           | ≈8:25 | Те саме, але за місяць                                                              |
| Якщо 1-ше число — понеділок | ≈8:25 | Лише місячне відео. Тижневе не викладаємо                                           |

## 1. Перевірити «Хвилину мовчання» (о 9:00)

- Відкрити канал @acmc_ua і переконатися, що о 9:00 вийшов допис
  «Хвилина мовчання».
- Якщо не вийшов — подивитися гілку **«Помилки»** у службовій групі й
  написати Юлі або Тетяні.

## 2. TikTok

1.  У гілці «TikTok» відкрити відео → **⋮** → **Зберегти в галерею**
    (Save to gallery).
2.  Відкрити застосунок TikTok під акаунтом АКМЦ → **+** → обрати відео
    з галереї.
3.  **Музику не додавати** — у відео вже є своя фонова музика.
4.  Скопіювати підпис з повідомлення бота і вставити в опис. Посилань на
    Telegram не додавати.
5.  **Опублікувати** (Post).

## 3. YouTube Shorts (канал АКМЦ)

1.  Відкрити studio.youtube.com → вгорі справа перевірити, що обрано
    **канал АКМЦ**, а не особистий.
2.  **Create** → **Upload videos** → обрати те саме відео.
3.  **Title** і **Description** — скопіювати з повідомлення бота «▶️
    YouTube Shorts».
4.  В описі має бути рядок із посиланням на Telegram — бот його вже
    додає. Посилання — саме **t.me/+XonxSiR7BTw3MjVi** («YouTube
    DeepState»), не загальне t.me/acmc_ua: так видно, скільки людей
    прийшло з YouTube.
5.  **Playlists** → поставити галочку **«DeepState: зміни на мапі
    Донеччини та Луганщини»**. Обов'язково: без цього відео не
    потрапить у рядок «🗺 DeepState» звіту аналітики. Назву плейлиста
    не змінювати.
6.  **Audience** → **No, it’s not made for kids**.
7.  **Show more** → **Category** → **News & Politics**.
8.  **Next** → **Next** → **Visibility: Public** → **Publish**.

## 4. Сторіз у Telegram-каналі

1.  У гілці «TikTok» зберегти картинку з підписом «📱 Для сторіз».
2.  Канал @acmc_ua → аватар каналу → **Додати історію** → обрати
    картинку.
3.  За бажанням: наліпка-посилання на допис із підсумком тижня в каналі.
4.  **Опублікувати**.

## 5. Make — швидка перевірка (раз на тиждень, 2 хвилини)

1.  make.com → увійти **своїм** акаунтом → **Scenarios**.
2.  Біля «📰 АКМЦ | Новини сайту → Телеграм» і «АКМЦ — кнопки
    аналітики» перемикач має бути **ON** (Active).
3.  Якщо OFF — Make вимкнув сценарій через помилки. Що робити — «07»,
    розділ «Якщо пости перестали з'являтися».
4.  Раз на місяць: **Org** → **Subscription** / **Usage** — чи не
    закінчуються операції на тарифі (від них залежить і ChatGPT у
    стрічці новин).

## Якщо щось пішло не так

| Що сталося                                       | Що робити                                                                                                                      |
|--------------------------------------------------|--------------------------------------------------------------------------------------------------------------------------------|
| До 8:30 у гілці «TikTok» нічого немає            | Подивитися гілку «Помилки». Якщо там порожньо — написати Юлі                                                                   |
| Замість відео прийшли 3 картинки                 | Відео не зібралося. У TikTok можна викласти їх як фото-допис з тим самим підписом. На YouTube цього тижня нічого не викладаємо |
| Бот написав «⚡ варто опублікувати» в інший день | Це щоденне відео при великих змінах. Не обов’язкове — вирішує редакція                                                         |
| YouTube не пускає в Studio                       | Значить, потрібен доступ до каналу. Його дає Тетяна Андрєєва                                                                   |

## Чого не робити

- Не пересилати в робочі чати паролі, коди й токени.
- Не змінювати налаштування бота на GitHub без Юлі.
- Не додавати до відео власних оцінок («звільнили», «втратили»): у
  текстах завжди «позначено».
